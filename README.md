# 📊 Dashboard de Ventas — Looker Studio

## Descripción
Dashboard interactivo de análisis de ventas retail usando Google Looker Studio
conectado a Google Sheets con datos de más de 9,000 registros.

## 🔗 Ver Dashboard en vivo
[👉 Haz clic aquí para ver el dashboard interactivo](https://datastudio.google.com/s/isiq2os7_D0)

## 📊 Visualizaciones incluidas
- **Ventas por Categoría** — Gráfica de barras comparativa
- **Tendencia Anual de Ventas** — Evolución 2014-2017
- **Ventas por Región** — Gráfica circular con 4 regiones
- **Top Productos más Vendidos** — Ranking por ventas

## 🛠️ Herramientas utilizadas
- Google Looker Studio (Data Studio)
- Google Sheets
- Dataset: Superstore Sales

## 📂 Dataset
[Superstore Dataset — Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
